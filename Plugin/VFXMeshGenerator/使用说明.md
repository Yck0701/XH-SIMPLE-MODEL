# VFX 特效网格生成器 1.1

在 Unreal 编辑器中调整网格参数，直接更新 Niagara 正在引用的静态网格资产。面板可停靠，不再需要从网页导出再导入。针对 UE 5.8.3 制作，包含中文界面和源码。

## 安装和打开

推荐使用同版本 Windows 启动器：选择 `.uproject`，点击“安装 / 更新插件”，首次安装后重启 UE，再点击“启动 UE / 打开面板”。启动器默认自动检查 GitHub 更新，并提供离线安装与备份恢复。

1. 将整个 `VFXMeshGenerator` 文件夹放入项目的 `Plugins` 目录。
2. 保存当前工作并重启 Unreal 编辑器。
3. 在菜单 **工具 → VFX 特效网格生成器** 打开面板，可将页签拖到 Niagara 窗口旁边。

插件依赖引擎内置的 Python Editor Script、Editor Scripting Utilities、Geometry Scripting、Niagara。插件描述文件会启用这些依赖，不需要编译 C++。若项目主动禁用了某项依赖，请在插件窗口启用它并重启。

## 第一次制作

1. 选择形状、尺寸及分段数，点击 **新建模型**。默认生成位置是 `/Game/VFXMeshes`；名称重复时自动使用新名称。
2. 点击 **查看模型** 打开静态网格预览，或在场景中摆放模型。
3. 在 Niagara 发射器添加 **Mesh Renderer（网格渲染器）**，将 **Meshes → 第 0 项 → Mesh** 指定为刚创建的模型。已有 Sprite Renderer 可根据特效需求关闭。
4. 保持面板中的 **实时更新** 开启。修改半径、分段、原点等参数后，约 0.25 秒触发一次网格重建，现有 Niagara 引用保持不变。
5. 满意后点击 **保存**。后续在内容浏览器选中模型，再点 **载入所选** 继续编辑。

模型是共享资产，所有引用它的发射器都会更新。需要独立变体时点击“新建模型”或复制静态网格资产后载入副本。不要用相同模型同时制作互不关联的形状。

## 支持的参数

- 平面、立方体、球、半球、圆柱、圆锥 / 圆台、圆环、十字面片、螺旋面片。
- 尺寸以厘米计；各形状分段、封盖、螺旋圈数和反向盘绕。
- 原点居中 / 底部、主轴方向、旋转、位移、法线翻转。
- “撤回上次调参”保留本次面板操作的最近 20 次记录。关闭编辑器后记录不会保留；模型已保存的生成参数会保留。

## 主贴图和遮罩

“工具材质”模式生成双面、无光照、半透明的材质实例。主贴图与遮罩直接使用项目中的 Texture2D，不需要重新导入已有贴图。

- 主贴图 RGB 控制颜色，Alpha 控制透明度。
- 遮罩读取 **R 通道**：黑色透明、白色显示。
- 主贴图和遮罩分别支持 U / V 翻转、旋转、U / V 流速；同一组的 UV 翻转开关放在一起。
- 最终颜色和透明度会乘以 Niagara 的粒子颜色和 Alpha。
- 选择“自定义 UE 材质”可使用已有特效材质；此时贴图和 UV 参数由该材质管理。

Niagara 如果启用了 Override Materials（覆盖材质），将优先显示渲染器指定的材质。要看到本面板的贴图效果，请使用网格自身材质，或把工具创建的 MI 指定给覆盖材质。

## 更新、保存和预览

实时调参修改的是内存中的静态网格，并标记为待保存。点击“保存”只保存当前网格及工具为它生成的材质实例；自定义材质不会被修改。新建和载入操作仅接受本工具的生成参数，不会覆盖无生成记录的现有模型。

Niagara 预览应处于播放状态，视口应开启实时刷新。网格重建会使引用它的 Niagara 系统重新初始化，因此粒子时间可能回到起点。这是编辑器制作工具，不适合逐帧动画或运行时蓝图变形。

默认关闭 Nanite，也不生成碰撞。本工具面向半透明特效网格；之前球模型明显切边的问题与 Nanite 的半透明回退有关。请保留此设置。

如果菜单未出现，可在 UE 输出日志中切换到 Python，执行：

```python
from vfx_mesh.runtime import open_panel
open_panel()
```

只有编辑参数需要 Python 和 Geometry Scripting。生成结果是普通 Static Mesh / Material Instance，可正常交给 Niagara、复制或迁移到其他工程。其他 UE 版本尚未验证；旧版本不一定能够打开 5.8 保存的面板及材质资产。
