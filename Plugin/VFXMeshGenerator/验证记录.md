# 验证记录

2026-10-12，在本机定制 Unreal Engine 5.8.3 的独立测试项目中验证。

- 九种形状均成功创建为 Static Mesh，Nanite 均关闭。
- 几何测试覆盖非退化三角形、单位法线、面朝向、UV 范围、圆周接缝、原点变换、零半径锥尖、反向螺旋以及无效参数保护。
- 50 × 32 球体为 3100 三角形、1681 个使用顶点，符合原工具结果。
- 面板数字控件回调将球半径更新为 150 cm；撤回操作恢复此前尺寸。
- Niagara 系统的 Mesh Renderer 引用保持相同资产对象及路径，更新后的包围盒半径正确变为 175 cm。
- 遮罩 FlipU 参数写入材质实例为 1；另起编辑器进程后，网格参数、材质参数及 Niagara 资产引用仍正确。
- 尝试编辑没有本工具元数据的模型时被拒绝，原有资产受到保护。
- 已检查原生面板的形状区、材质选择区与 UV 翻转布局。

该版本只用于编辑器制作；尚未验证其他引擎版本或游戏项目的完整打包流程。测试工程和测试用 C++ 工具不随插件发布。
