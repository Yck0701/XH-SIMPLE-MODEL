从旧版升级到 1.2.0：先保存自己的工作并关闭该工程，安装更新后重新打开 UE。

01

安装并打开工作台

完整解压启动器 ZIP，保留 EXE 旁边的 _internal 和 offline 目录。选择工程 .uproject，确认对应的 UnrealEditor.exe，再点击“安装 / 更新插件”。首次安装及升级到 1.2.0 后重新打开 UE。

入口：UE 顶部“特效网格 → 打开独立工作台”，或启动器“启动 UE / 独立工作台”。窗口可最大化，也可以把页签停靠在编辑器内。

02

左侧调参数，右侧看模型

点击“新建预览”，选择球、圆环等形状，开启“实时更新”后拖动尺寸与分段参数。旋转和位移的 X/Y/Z 放在同一行。新建预览不会创建或保存资产。

预览操作：左键拖动旋转，中键拖动平移，滚轮或右键拖动缩放。在视口中按 F 或点击“聚焦”找回模型。下方可切换坐标轴 / 原点、网格、地板、环境和自动旋转。

03

使用自己的材质

在“当前材质”选择已有材质或材质实例；也可以在内容浏览器选中材质，点击“使用所选材质”。点击“编辑当前材质”打开它的 UE 原生编辑器。

主贴图、遮罩、UV、流速等参数由你的材质提供，在材质实例编辑器中调整。本工具不会新建工具材质，也不会替你保存材质。使用 Particle Color 等 Niagara 数据的最终效果请在 Niagara 中预览。

04

选择 UE 目录，确认保存

点击“浏览内容目录”，在内容浏览器选一个 /Game 下的文件夹，然后点击“使用所选目录”。输入模型名称；留空时自动命名，重名时自动增加后缀。

点击“保存模型…”后，确认框会显示确切资产路径。确认只保存当前模型及生成参数；取消不会写文件。已有模型保存在原位置，不会因目录选择而移动。关卡、材质和其他脏资产不会被这次保存带上。

05

给 Niagara 使用，继续实时调整

打开 Niagara System → 选发射器 → Mesh Renderer → Meshes → 第 0 项 → Mesh，选择刚保存的模型。没有条目时先按 +。

继续在工作台调参会更新同一个 Static Mesh，Niagara 无需重新指定。多个地方引用同一模型会同时变化。下次从内容浏览器选中模型，点“载入所选模型”；调好后再次确认保存。

更新与常见问题

预览环境是什么

右侧使用 SEditorViewport 和 FAdvancedPreviewScene，与 UE 官方资产编辑器使用同一套视口与高级预览场景体系，包含环境 HDRI、灯光、地面和后处理。场景独立于当前关卡，不会往关卡添加模型或灯光。最终效果仍取决于材质、引擎渲染设置及 Niagara 的粒子数据。

自动更新与热更新

每次启动默认检查本 GitHub 仓库正式发行版，也可在“更新中心”手动检查。检查不会强制安装或关闭 UE。兼容的 Python 脚本更新可保留当前模型与未保存参数并热重载；面板、原生 DLL、依赖或连接组件变化需要先关闭该工程。1.2.0 属于需要重启的更新。旧启动器先点“更新启动器并重开”，再更新插件。

备份与恢复

更新前会备份到 工程/Saved/VFXMeshGenerator/backups。需要恢复时，保存自己的工作并关闭该工程，在启动器“备份与恢复”中恢复上次备份。恢复的是插件，不会删除 Content 中的模型。网络不可用时可使用启动器内置离线包。

找不到插件或无法安装

确认启动器选择了当前工程。重启 UE 后查看顶部“特效网格”菜单，并检查 Python、Geometry Scripting 等依赖已启用。1.2.0 原生预览只接受包中匹配的 UE 5.8.3 构建；引擎不匹配时需要维护者构建适配组件，不能只修改版本号强行加载。

材质没有变化或球体切边

检查 Niagara 的 Override Materials 是否覆盖了模型材质。半透明特效网格请保持 Nanite 关闭。旧版生成的工具材质仍可作为已有用户材质继续使用，新工作台不会替它调整或保存参数。

保存和撤回的范围

实时更新会修改已载入模型的内存状态并将其标记为待保存；插件自己的保存按钮每次都需要确认，只保存该模型。UE 自带的“保存所有”和自动保存遵循编辑器自身设置。“撤回”用于本次参数历史；关闭 UE 后历史不保留，已保存的生成参数会保留。网格重建可能让 Niagara 重新初始化。当前功能用于编辑器制作，不是运行时逐帧变形。
