02

打开面板，新建模型

点击启动器的 启动 UE / 打开面板。工程加载完成后面板会自动打开。选择“球”或“圆环”等形状，点击 新建模型。

默认生成位置：内容浏览器 /Game/VFXMeshes，模型名称以 SM_VFX 开头。也可在 UE 的“工具”菜单中打开 VFX 特效网格工具。

03

让 Niagara 引用它

打开 Niagara System，选中需要显示网格的发射器，在渲染器中添加或选中 Mesh Renderer（网格体渲染器）。

04

拖动参数，立即看效果

开启面板的 实时更新，拖动半径、分段、变换等参数。更新的是同一个模型，Niagara 会使用更新后的结果，无需重新指定。

主贴图

控制模型的外观与颜色。U / V 翻转放在一起，旋转与流速可以独立调整。

遮罩贴图

取 R 通道：白色显示，黑色隐藏。遮罩也有独立 UV 翻转、旋转与流速。

关闭实时更新后，可在调好参数后点击 立即应用参数。多个发射器引用同一模型会一起变化，需要不同形状时创建不同模型。

以后如何更新？

每次打开启动器，默认自动检查 GitHub 正式版本。发现新版后点击 安装 / 更新插件；也可以到“更新中心”手动检查。

兼容脚本更新

UE 连接就绪时直接热重载，保留面板中的当前模型和未保存参数。第一次启用连接需要重启一次 UE。

面板 / 材质资源更新

按提示保存并关闭工程，再点击更新。完成后重新打开 UE。启动器不会自动关闭你的工程。

启动器自身有新版时，点击“更新启动器并重开”。断网时可继续使用当前版本或内置离线包。每次更新前会备份旧插件；下载包校验通过后才会安装。

常见问题

如何恢复上一个插件版本？

保存并关闭工程 → 启动器“备份与恢复” → “恢复上次备份” → 重启 UE。备份在 工程/Saved/VFXMeshGenerator/backups。你在 Content 里保存的模型会保留。

Niagara 的材质为什么没有变化？

检查 Mesh Renderer 的 Override Materials（覆盖材质）。启用覆盖材质时，Niagara 可能没有使用模型自身的材质。

球体切边，应该检查什么？

本工具默认关闭 Nanite。半透明特效模型请保持 Nanite 关闭。

找不到面板或热更新暂时无响应？

确认启动器选择的是当前工程，首次安装后重启 UE，并确认 Python、Geometry Scripting 等依赖启用。UE 正在编译或有弹窗时，先完成操作再重试。

可以在游戏运行时改变形状吗？

当前用于编辑器制作。生成的结果是普通 Static Mesh 和材质，不包含游戏运行时变形功能。
