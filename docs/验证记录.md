# 1.3.0 验证记录

验证日期：2026-10-12。Windows 11 x64，官方与定制 UE 5.8.3 的隔离工程，DX11。

- 两个引擎冷启动并加载各自原生组件，材质预览、模型线框与坐标轴可见。线框仅用于预览，不修改模型或材质资产。
- 两个工程均验证数值、颜色 / 向量、贴图和静态开关读写，以及取消覆盖后恢复继承值。
- 实时调材质与取消保存写入 0 个 Content / Config 文件；确认保存材质只改动目标实例；保存模型时材质与母材质的未保存修改保持不变。
- 创建材质实例取消时写入 0 个文件，确认后只创建目标实例文件，不保存母材质或模型。
- 热重载保留未提交的材质参数、线框开关和当前模型；关闭重开工作台仍保留编辑对象。
- 官方引擎通过真实侧栏输入将粗糙度从 0.64 改为 0.2，预览高光即时改变；线框开关进行了界面验证。
- 15 项启动器测试通过。保存验证脚本：`tests/ue_workspace_verify.py`、`tests/ue_material_verify.py`。

侧栏支持普通全局数值、颜色、贴图和静态开关参数。分层、重名及其他高级参数使用 UE 原生材质编辑器。线框显示生成网格的基础拓扑，不随材质世界位置偏移变形。未测试其他引擎构建或完整游戏打包。

## 1.2.0 历史验证

验证日期：2026-10-12。Windows 11 x64，官方及定制 UE 5.8.3 的独立测试工程，DX11。

- 15 项启动器测试通过：安装、更新、备份回退、损坏下载、版本发现、启动自动检查、启动器自身升级，以及引擎 BuildId / DLL 指纹不匹配时不改动已安装插件。
- 两个引擎均成功加载各自原生预览 DLL，显示官方高级预览场景。独立窗口首次打开调整为 1200×800，参数在左、预览在右。
- 实际鼠标旋转记录到相机角度变化；官方引擎滚轮缩放改变相机距离。按键映射沿用原生资产预览视口：左键旋转、中键平移、右键缩放，额外提供 F 聚焦。
- 两个引擎均执行真实保存隔离测试：新建预览和取消保存写入 0 个文件；确认新建及再次确认保存，均只改动当前模型的 `.uasset`。另外的脏材质、脏模型保持未保存；关卡 Actor 数量不变，模型引用保持不变。
- 原生材质编辑器成功打开指定用户材质；热重载保留当前网格、未保存参数、预览开关；关闭并重新打开工作台后仍保留编辑对象。
- 两个测试编辑器均正常退出。真实工作工程未被关闭或保存。

测试脚本：`tests/test_launcher.py`、`tests/ue_workspace_verify.py`。预览使用独立场景，最终 Niagara 粒子数据和具体项目的渲染效果需在对应项目中检查。其他引擎构建及完整游戏打包流程未验证。

## 1.1.0 历史验证

验证日期：2026-10-12。环境：Windows 11 x64、Python 3.14、PyInstaller 6.22.3、定制 Unreal Engine 5.8.3。

- 启动器单元测试覆盖冷安装、升级、备份恢复、拒绝降级、依赖禁用提示、路径与下载校验、损坏下载清理、正式版本发现、启动自动检查及设置保存。
- 在独立 UE 工程中确认启动参数可自动打开面板，连接心跳与“打开”请求有效。
- 真实脚本包热更新得到 UE 成功响应。网格资产路径、未保存的半径 177、遮罩翻转、实时更新关闭状态及对应控件、待修改标记、模型名与保存目录均保留。
- 使用故意含 Python 语法错误的测试更新，确认安装报错、文件恢复为上一版本、旧版本重新载入且面板仍可打开。
- PyInstaller EXE 的内置插件包 SHA-256 校验及教学文件检查通过，实际 GUI 可正常打开。
- 资源更新在编辑器运行时被拒绝；首次安装到旧版正在运行的工程，会明确提示重启以激活连接。

原插件九种形状、Niagara 引用与 UV 的验证见 `Plugin/VFXMeshGenerator/验证记录.md`。其他引擎版本及完整游戏打包流程尚未验证。
