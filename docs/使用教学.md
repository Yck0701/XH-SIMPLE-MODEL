# 从安装到 Niagara：5 步开始

适用于启动器与插件 1.5.0。

## 1. 安装并打开工作台

完整解压启动器 ZIP，保留 EXE 旁边的 _internal 和 offline 目录。选择工程 .uproject，确认对应的 UnrealEditor.exe，再点击“安装 / 更新插件”。首次安装及升级到 1.5.0 后重新打开 UE。

入口：UE 顶部“特效网格 → 打开独立工作台”，或启动器“启动 UE / 独立工作台”。窗口可最大化，也可以把页签停靠在编辑器内。

## 2. 左侧模型，中间预览，右侧材质 / 环境

点击“新建参数模型”，选择球、圆环等形状，圆柱 / 圆台的顶盖和底盖、半球底盖默认关闭；需要封口时再勾选。开启“实时更新”后拖动尺寸与分段参数。旋转和位移的 X/Y/Z 放在同一行。新建预览不会创建或保存资产。左侧分为“形状与尺寸”“原点与变换”“保存位置”，点击标题折叠。拖动中间两条分隔线可手动调整三栏宽度；点击“重置布局”恢复默认比例。标题和参数标签保持单行，完整文字可悬停查看；说明文字按栏宽自然换行。顶部“模型参数”和“材质 / 环境”可收起两侧栏，把空间留给预览。

预览操作：左键拖动旋转，中键拖动平移，滚轮或右键拖动缩放。在视口中按 F 或点击“聚焦”找回模型。下方“模型线框”以透视方式叠加青色三角线（含背面布线），避免贴面深度冲突，可随时开关，不改变导出的模型或材质。线框旁的“不透明度 %”可拖动或输入 0–100，默认 35；0 完全隐藏，100 完全不透明，重新加载面板后保留当前值。线框表示基础网格，不随材质的世界位置偏移变形。工具条可切换坐标轴 / 原点、网格、自动旋转和“投射阴影”；阴影开关只作用于预览，Niagara 中请使用 Mesh Renderer 自己的阴影设置。地板和环境显示移至右侧“环境设置”。

在内容浏览器选择网格后点击顶部“载入所选网格”：本工具生成的模型会恢复参数，普通静态 / 骨骼网格进入自定义预览。也可展开左侧“自定义模型 / 动画”直接使用原生资产选择器。自定义模型保留原几何，生成参数会禁用；材质替换只影响预览的第 0 个材质槽，其他槽保持模型原材质。

“导入模型文件…”先确认新建的 /Game 导入目录，再打开 UE 原生导入窗口；可在其中选择骨骼网格与导入动画。骨骼模型勾选“使用模型动画”，选择同骨架动画序列，可播放 / 暂停、循环、调整 0.1–4 倍速度或回到开头。不同骨架请先在 UE 重定向。动画仅在工作台预览，Niagara Mesh Renderer 仍引用静态网格；骨骼预览暂不提供拓扑线叠加。

导入完成后，点击“保存导入资产…”逐项确认并保存本次导入目录内的模型、骨架、动画等关联资产。查看已有自定义模型不需要重新保存网格，顶部隐藏无效的模型保存按钮；材质实例参数仍从右栏单独保存。

## 3. 使用自己的材质

在“当前材质”的原生选择器中指定材质，也可使用选择器自带的“使用内容浏览器中选择的资产”箭头。选好后直接在下方细节栏调整，不再提供重复的选材质或独立编辑按钮。默认编辑临时预览副本，原材质不变。

选择当前工程的材质实例后，最右侧“材质细节”使用 UE 原生参数控件，保留母材质分组、排序、数值范围、枚举、贴图选择器和静态开关。颜色参数点左侧三角可展开 R/G/B/A，点击色块打开原生取色器。顶部可搜索参数，齿轮菜单可筛选已覆盖参数；“显示未激活参数”用于查看被静态开关隐藏的参数。勾选参数左边的覆盖开关，即可实时调整；取消勾选恢复父材质值。主贴图、遮罩、UV、流速等需要先由你的母材质暴露为参数。静态开关改变时需要等待 UE 编译着色器。

展开材质页的“通用 → 材质属性重载”，可调整父材质、物理材质、Lightmass、折射深度偏离、混合模式、双面、着色模型、位移、阴影和 Nanite 覆盖。先勾选每行左侧覆盖框，再调值；取消覆盖继承父材质，重置箭头恢复父材质值。引擎限制的选项遵循原生行为，定制引擎另有 JX3 Blend Mode；更改混合模式等属性需要等待着色器编译。父材质不能选择当前实例或它的子实例。

点击“保存材质…”后会打开独立确认弹窗，选择“替换原材质并保存”把当前参数写回原实例，保留引用；“新增实例并保存”把当前调整另存为新实例。新实例使用内容浏览器选中的 /Game 目录，弹窗内可修改实例名称，完整路径实时更新；空名称、非法字符和重名会提示并禁用新增按钮。未选择目录时使用原材质目录。确认框显示完整目标路径，确认后只保存该实例；取消不写文件。侧栏持续显示未保存、已保存或保存失败；保存成功显示时间与资产路径，并在内容浏览器定位。模型与材质分别保存。母材质或引擎资产通过新实例保存，不覆盖母材质。

需要在 Niagara 或关卡里边调边看时，开启“实时迭代原材质”并确认：当前副本参数立即应用到原实例，后续修改同步影响所有引用。写入磁盘仍需点保存。关闭开关后回到副本预览，不撤销已应用的原实例修改；可用 UE 撤销恢复。这个开关适用于当前工程的材质实例，母材质请先新增实例。另存新实例也不会撤销此前的实时迭代。

分层参数按图层 / 混合索引区分；材质图层堆栈结构、参数集合、自定义图元数据使用 UE 完整编辑器，在内容浏览器双击资产即可。使用 Particle Color 等 Niagara 数据的最终效果请在 Niagara 中预览。

## 4. 选择 UE 目录，确认保存

点击“浏览内容目录”，在内容浏览器选一个 /Game 下的文件夹，然后点击“使用所选目录”。输入模型名称；留空时自动命名，重名时自动增加后缀。

点击“保存生成模型…”后，确认框会显示确切资产路径。确认只保存当前模型及生成参数；取消不会写文件。已有模型保存在原位置，不会因目录选择而移动。关卡、材质和其他脏资产不会被这次保存带上。

## 5. 给 Niagara 使用，继续实时调整

打开 Niagara System → 选发射器 → Mesh Renderer → Meshes → 第 0 项 → Mesh，选择刚保存的模型。没有条目时先按 +。

继续在工作台调参会更新同一个 Static Mesh，Niagara 无需重新指定。多个地方引用同一模型会同时变化。下次从内容浏览器选中模型，点“载入所选网格”；调好后再次确认保存。

## 调整预览环境

右侧点击“环境设置”，在原生细节控件中调整 HDRI 立方体贴图、环境光强度 / 旋转、主光强度 / 方向 / 颜色、自动曝光 / 曝光补偿、泛光、背景颜色 / 强度、地板显示 / 高度和后处理。关闭自动曝光后，曝光补偿仍可用。按住 K 或 L 并在视口拖动，可调整环境或主光方向；侧栏数值同步。点击“重置环境”恢复本次打开时的环境。

环境仅作用于这个工作台，不写入关卡、资产或 UE 全局预览配置；重新加载面板保留本次设置，重启编辑器后恢复初始环境。

中间预览使用 SEditorViewport 和 FAdvancedPreviewScene，与 UE 官方资产编辑器使用同一套视口与高级预览场景体系，包含环境 HDRI、灯光、地面和后处理。场景独立于当前关卡，不会往关卡添加模型或灯光。最终效果仍取决于材质、引擎渲染设置及 Niagara 的粒子数据。

## 自动更新与热更新

每次启动默认检查本 GitHub 仓库正式发行版，也可在“更新中心”手动检查。检查不会强制安装或关闭 UE。兼容的 Python 脚本更新可保留当前模型与未保存参数并热重载；面板、原生 DLL、依赖或连接组件变化需要先关闭该工程。1.5.0 属于需要重启的更新。旧启动器先点“更新启动器并重开”，再更新插件。

## 备份与恢复

更新前会备份到 工程/Saved/VFXMeshGenerator/backups。需要恢复时，保存自己的工作并关闭该工程，在启动器“备份与恢复”中恢复上次备份。恢复的是插件，不会删除 Content 中的模型。网络不可用时可使用启动器内置离线包。

## 找不到插件或无法安装

确认启动器选择了当前工程。重启 UE 后查看顶部“特效网格”菜单，并检查 Python、Geometry Scripting 等依赖已启用。1.5.0 原生预览只接受包中匹配的 UE 5.8.3 构建；引擎不匹配时需要维护者构建适配组件，不能只修改版本号强行加载。

## 材质没有变化或球体切边

检查 Niagara 的 Override Materials 是否覆盖了模型材质。半透明特效网格请保持 Nanite 关闭。旧版工具材质实例也可在新侧栏调整，确认后选择替换或另存。预览副本默认不影响 Niagara；需要即时联动时开启“实时迭代原材质”。

## 保存和撤回的范围

实时更新会修改已载入模型的内存状态并将其标记为待保存；插件自己的保存按钮每次都需要确认，只保存该模型。UE 自带的“保存所有”和自动保存遵循编辑器自身设置。“撤回”用于本次模型参数历史；材质更改进入 UE 撤销记录，侧栏“刷新参数”可同步原生编辑器或撤销后的值。关闭 UE 后历史不保留，已保存的生成参数会保留。网格重建可能让 Niagara 重新初始化。当前功能用于编辑器制作，不是运行时逐帧变形。
