# 从安装到 Niagara：5 步开始

## 1. 安装到你的工程

从 [发行版页面](https://github.com/Yck0701/XH-SIMPLE-MODEL/releases/latest) 下载 **VFXMeshLauncher-版本-Windows.zip**。完整解压，保留 EXE 旁边的 `_internal`、`offline` 等目录。

双击 **VFX特效网格启动器.exe** → 选择工程的 `.uproject` → 确认 UnrealEditor.exe → 点击 **安装 / 更新插件**。首次安装后保存并重启 UE。启动器会记住路径，之后不用重新选择。

插件安装位置是 `你的工程/Plugins/VFXMeshGenerator`。使用其他工程时，再选择那个工程安装一次即可。

## 2. 新建一个模型

在启动器点 **启动 UE / 打开面板**。UE 启动完成后会自动打开特效网格面板。也可以在 UE 的“工具”菜单中找到 VFX 特效网格工具。

选择球、圆环等形状，点击 **新建模型**。默认保存目录是内容浏览器的 `/Game/VFXMeshes`，模型以 `SM_VFX` 开头。先创建模型，再调参数。

## 3. 让 Niagara 使用这个模型

打开 Niagara System → 选中发射器 → 添加或选中 **Mesh Renderer（网格体渲染器）** → 展开 **Meshes** → 第 **0** 项 → **Mesh** → 选择刚创建的模型。

如果列表没有条目，先点击 `+` 增加一个。只使用网格显示时，可以移除不需要的 Sprite Renderer。粒子位置、数量、颜色仍由 Niagara 控制；本插件负责模型形状和模型材质。

## 4. 开始调形状与贴图

在插件面板开启 **实时更新**，拖动半径、分段等参数。更新的是同一个 Static Mesh，Niagara 引用无需反复替换。多个地方引用该模型时会一起变化；需要不同形状时请新建不同模型。

主贴图和遮罩贴图可分别选择，遮罩取 **R 通道：白色显示、黑色隐藏**。各自的 U/V 翻转放在一起，也可以分别设置旋转和流速。不想自动应用时关闭实时更新，调好后点 **立即应用参数**。

如果材质没有变化，检查 Niagara 的 **Override Materials（覆盖材质）**：覆盖材质开启时，可能挡住模型自身的材质。需要专用效果时可使用自定义 UE 材质。

## 5. 保存和继续编辑

满意后点 **保存**。实时预览不会自动保存到磁盘。下次在内容浏览器选中模型，再点击面板的 **载入所选**，即可恢复保存过的参数并继续编辑。面板的撤回用于最近的调参操作。

## 更新怎么用

每次打开启动器，会自动检查本仓库正式发行版；也可以在 **更新中心 → 立即检查** 手动刷新。看到新版后点击 **安装 / 更新插件**。

- 普通脚本更新：UE 正在运行且连接正常时，自动热重载并保留当前参数。
- 第一次升级到支持热更新的版本：安装后保存并重启 UE 一次。
- 面板、材质资源、依赖或连接组件更新：按提示保存并关闭工程，再点击更新，完成后重开工程。
- 启动器新版：点 **更新启动器并重开**。旧的入口下次启动会转到已验证的新版本。
- 网络不可用：继续使用已安装版本或内置离线包，联网后再检查。

自动检查不会自动强制安装，也不会关闭你的工程。工程路径只保存在本机；更新请求只访问发行版和下载文件。

## 更新异常时恢复

保存并关闭该工程 → 启动器 **备份与恢复 → 恢复上次备份** → 重新启动 UE。备份位于 `工程/Saved/VFXMeshGenerator/backups`。恢复的是插件；你保存在 Content 目录里的模型仍然保留。

## 常见问题

**找不到面板：** 确认选择的是当前工程，重启 UE；检查 Python、Geometry Scripting 等依赖是否启用。编辑器忙于编译或有弹窗时，先完成操作再点击打开面板。

**球体切边：** 本工具默认关闭 Nanite。半透明特效网格请保持 Nanite 关闭。

**启动器无法打开：** 请先完整解压，勿单独移动 EXE；不需要额外安装 Python。当前仅提供 Windows x64 版本。

**要在游戏运行中改形状？** 当前版本用于编辑器内制作，不包含游戏运行时变形功能。
