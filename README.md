# VFX 特效网格生成器

在 Unreal 编辑器中调节网格参数，使用自己的材质，通过原生视口实时预览。Niagara 引用一次 Static Mesh 后，继续调整同一个模型即可。

**[下载 Windows 启动器](https://github.com/Yck0701/XH-SIMPLE-MODEL/releases/latest)** · **[5 步使用教学](docs/使用教学.md)**

当前正式版：**1.5.6（2026-10-13）**。[直接下载启动器 ZIP](https://github.com/Yck0701/XH-SIMPLE-MODEL/releases/download/vfx-v1.5.6/VFXMeshLauncher-1.5.6-Windows.zip) · [版本说明与校验文件](https://github.com/Yck0701/XH-SIMPLE-MODEL/releases/tag/vfx-v1.5.6)。完整解压并保留 `compiler`、`offline`、`_internal` 文件夹。

## 三步开始

1. 完整解压 `VFXMeshLauncher-1.5.6-Windows.zip`，双击 `VFX特效网格启动器.exe`。无需安装 Python。
2. 选择 `.uproject` 和对应引擎，点击 **安装 / 更新插件**。从 1.5.4 升级可热更新；其他版本按启动器提示先保存工作并关闭对应工程。
3. 重新打开 UE，在顶部 **特效网格 → 打开独立工作台** 进入。左侧调模型、中间看预览、右侧调材质；点击左侧“保存位置”下方的 **保存生成模型…** 并确认后生成资产。

## 1.5.6 修复引擎选择与检测提示

- 手动选择引擎后，即使版本信息读取失败也保留所选路径；检测、编译和安装使用同一条已规范化路径。
- 接受复制路径时附带的引号和首尾空格，也可输入引擎根目录、Engine 目录或 Win64 目录。路径不存在时显示具体位置；空路径、版本不支持和文件读取失败分别提示。
- UE 描述文件支持引擎文件读取器允许的注释与尾逗号，仅读取，不重写工程或引擎文件。安装包清单、更新源和编译回执继续要求严格 JSON。
- JSON 失败显示出错文件、原始行列及处理建议；同步和异步错误都先记录到 `%LOCALAPPDATA%/VFXMeshLauncher/launcher.log`，再弹窗。
- **先更新启动器到 1.5.6**，再检测兼容性；只更新 UE 插件不能修复旧启动器的提示。BuildId、版本与 DLL 指纹检查不变。

## 功能

- 原生预览使用 UE 标准内存分配器；回收旧面板时解绑事件并释放原生视图。
- 材质预览复用网格，模型修改共用一次几何生成；热重载保留已验证的 DLL 句柄。
- 防止弹窗和保存期间回调重入；工程写入路径拒绝指向其他目录的链接。

- 独立可停靠工作台，可拖动分隔线的三栏布局，九种参数化网格。
- UE 原生视口与官方高级预览场景：左键旋转、中键平移、滚轮或右键拖动缩放、F 聚焦。
- 右侧环境页实时调整 HDRI、环境光、主光、曝光、泛光、背景和地板；只影响工作台，不改全局预览配置。
- 自定义静态 / 骨骼模型导入与预览，支持可选骨骼动画的播放、暂停、循环和速度；动画仅用于工作台。
- 顶盖 / 底盖默认关闭，预览支持投射阴影开关。
- 左侧参数分区折叠，顶部可隐藏两侧栏；材质 / 环境页签共用右栏。
- 材质效果上叠加可开关的模型线框；改用稳定的编辑器透视叠加，显示包含背面的完整布线，消除贴面深度冲突；线框不透明度可在 0–100% 间实时调整，默认 35%。
- 最右侧使用 UE 原生材质细节控件：分组排序、搜索、RGBA 展开、范围滑块、枚举、贴图和静态开关，支持继承 / 覆盖。
- 材质页补齐“通用 / 材质属性重载”：父材质、混合模式、双面、Lightmass、位移、Nanite 覆盖；定制引擎支持 JX3 Blend Mode。
- 材质默认在预览副本中调整；独立保存弹窗可替换原实例或命名新增实例，显示重名提示、成功 / 失败和目标路径。
- 可开启“实时迭代原材质”，直接修改工程材质实例并联动 Niagara；写入磁盘仍需确认。
- 模型保存按钮位于左侧“保存位置”下方，与目录和模型名集中显示；折叠路径设置后仍可保存。顶部保留新建、载入和定位入口。
- 新建只生成预览草稿；目录从内容浏览器获取，每次确认保存只写当前模型。
- 编辑器内更新同一个 Static Mesh，已有 Niagara 引用保持不变；参数随模型保存，支持载入和撤回。
- 启动器启动自动检查 GitHub 更新，包含离线包、SHA-256 校验、更新前备份、失败回退及启动器自身更新。
- 兼容脚本更新支持热重载；面板、原生组件、依赖或连接组件变化时需要关闭工程更新。

## 适用环境

Windows x64，启动器接受 **UE 5.8** 并在安装前检查具体构建。1.5.6 沿用 1.5.4 的以下三套 UE **5.8.3** 组件：

| 引擎构建 | BuildId | 验证状态 |
| --- | --- | --- |
| 官方 UE 5.8.3，CL 58210709 | `55116800` | 真实编译与独立编辑器验证通过 |
| 公司先前构建 | `93941773-5036-42be-9ee8-469d175d5470` | 保留此前通过验证的组件 |
| 公司当前构建 | `210891e3-aa60-4f7b-ac84-35d0b26d09fc` | 真实编译与独立编辑器验证通过 |

版本号或 BuildId 相同不代表兼容，仍需 DLL 指纹匹配；盘符不参与匹配。其他 UE 5.8 构建可使用启动器的“为当前引擎编译适配”。**UE 5.8.2 尚未实机验证**，需在目标电脑用该引擎完整开发文件完成编译和独立验证。

插件用于编辑器制作，不包含运行时变形。依赖 Python Script Plugin、Editor Scripting Utilities、Geometry Scripting 和 Niagara。半透明特效网格默认关闭 Nanite、不生成碰撞。

预览使用 UE 官方资产预览场景体系，不会复制当前关卡的灯光。Niagara 的粒子颜色、时间、覆盖材质仍应在 Niagara 编辑器中检查。旧版工具材质资源保留用于已有资产兼容，新界面使用用户材质。

## 源码与维护

- `Plugin/VFXMeshGenerator`：Python 工作台、网格生成与小型原生预览适配组件源码。
- `Launcher`：Windows 启动器。
- `tests`：安装、更新、回退测试及隔离 UE 工程中的保存验证脚本。
- `Launcher/native_builder.py`：启动器本机编译、工具链检测、独立验证和适配缓存。
- `scripts/RulesHelper`、`scripts/CompilerHost`、`scripts/verify_native.py`：随启动器分发的构建与验证附件。
- `scripts/build_native.py`：维护者手动构建脚本，具体限制见发布流程。
- `scripts/build_release.py`：构建 EXE、离线插件和发行清单。
